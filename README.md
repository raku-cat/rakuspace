# RakuSpace

A little vibecoded project for a simple streaming solution using OvenMediaEngine and OvenPlayer paired with a flask app for a frontend with a name inspired by AirenSoft's OvenSpace app. The flask app and its setup is located in [frontend](/frontend) and the supporting OvenMediaEngine config is located in [backend](/backend).
An optional OBS Studio plugin lives in [obs-plugin](/obs-plugin) — it adds a "RakuSpace" streaming service to OBS and an optional Discord Rich Presence card while you are live; see [obs-plugin/README.md](/obs-plugin/README.md).
Have fun!
